SYSTEM DESIGN

Designed around control boundaries, not just model calls.

The prototype separates document handling, sensitive-data controls, evidence retrieval, reasoning, permissions and external execution.

01 · INPUTProgramme reportSource preserved + fingerprinted
→
02 · GUARDPII / safeguardingClassify + minimise context
→
03 · EVIDENCERAG + claim checkRetrieve + link + score
→
04 · AGENTPropose actionDraft only
→
05 · AUTHORITYHuman approvalExplicit side-effect gate
→
06 · EXECUTEWorkflow adaptern8n / Power Automate pattern
01

Evidence first

Important claims link back to supporting passages. Missing evidence is a first-class result.

02

Minimise before model

Sensitive identifiers are removed from model context before generation, not scrubbed afterwards.

03

Least privilege

The agent can prepare a follow-up but cannot execute external side effects without authority.

04

Replayable decisions

Inputs, retrieval, policies, approvals and actions leave inspectable events for review and debugging.
